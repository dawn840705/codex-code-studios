# Lesson Capture Rules (교육용 노하우 상시 캡처)

> 이 스튜디오의 모든 프로젝트는 게임 개발물이자 **교육 자료** (게임 기획자 과정 — 바이브 코딩 강의 소스) 다.
> 개발 중 얻은 노하우는 `Documents/Lessons/` 에 표준 포맷 (templates/lesson.md) 으로 축적한다.

## 캡처 트리거 5종 — 하나라도 발생하면 레슨 기록을 제안하거나 수행할 것

1. **반복된 함정** — 같은 실수/함정이 2회 이상 반복됨 (예: 코드 기본값 변경이 prefab 직렬화 값에 무효)
2. **사용자 지적으로 드러난 설계 구멍** — 실플레이 피드백이 시스템 규칙의 빈틈을 노출
3. **검증으로 뒤집힌 가정** — 봇/실측/데이터가 "그럴 것이다"를 반증
4. **도구·워크플로우 함정** — 엔진/CLI/AI 협업 과정의 비직관적 동작과 우회법
5. **기획 의사결정 패턴** — 게임 문법·텔레그래프·밸런스 원칙이 데이터/피드백으로 확정된 순간

## 기록 규칙

- 위치: 프로젝트의 `Documents/Lessons/LES-YYYYMMDD-NN-<slug>.md` + `INDEX.md` 한 줄 갱신
- 포맷: `templates/lesson.md` — 특히 **"시도와 실패" 절 생략 금지** (실패 과정이 강의의 본체)
- 카테고리 5종: `vibe-coding` / `game-design` / `engine-tech` / `test-balancing` / `production-ops`
- 난이도: 입문 (도구 함정·단일 개념) / 중급 (시스템 간 상호작용) / 심화 (설계 판단·검증 방법론)
- 타이밍: 발생 직후가 최선, 늦어도 그날 마감 회의 전. 몰아서 쓰면 실패 과정의 디테일이 소실됨
- 결정 기록 (회의록) 과 중복 OK — 관점이 다름 (회의록 = 무엇을 결정했나, 레슨 = 무엇을 배웠나)

## 재발 방지 규칙으로 연결

- 확인된 원인과 다음에 취할 행동을 짧게 정리하고 근거 레슨/검증 기록을 연결한다.
  상세 실패 과정은 레슨에 보존하고, 반복 사용될 행동만 프로젝트의 기존 계약이나
  관련 공통 규칙에 반영한다. 사건마다 AGENTS.md·CLAUDE.md에 전문을 복제하지 않는다.
- 같은 의미의 규칙이 있으면 해당 조항을 보완한다. 작업 중 갱신하는 조항 범위에서
  중복을 통합하며, 이를 전체 계약 재작성이나 별도 정리 자동화로 확대하지 않는다.
- [공유 기록 원칙](work-records.md)에 따라 런타임별 진입점은 같은 정본을 읽게 한다.
  규칙의 중복 정리는 아래의 레슨 원본·오진 이력 보존을 폐지하지 않는다.

## 레슨을 정정할 때 — 지우지 말고 대체한다

같은 사건을 다시 진단해서 **이전 레슨이 틀린 것으로 드러나면**, 그 레슨을 고치거나
지우지 않는다. 새 레슨을 쓰고 프론트매터에 `supersedes: LES-YYYYMMDD-NN` 을 건다.

- **옛 레슨은 그 자리에 그대로 둔다.** 틀린 진단 자체가 강의 자산이다 — "절차를
  밟았는데도 틀린" 사례는 절차의 한계를 가르치는 유일한 재료이고, 지우면 남는 것은
  정답뿐이라 학생은 그것이 왜 어려웠는지 볼 수 없다.
- **INDEX 에 두 표시를 남긴다**: 새 레슨 줄에 `**(NN을 대체)**`, 옛 레슨 줄에
  `⚠️ **오진 사례로 보존**`. `$lesson-review` 가 INDEX 를 재생성하므로, 이 표기가
  규약이 아니면 재생성 때 대체 관계가 사라진다.
- **짝으로 강의한다.** 옛 레슨 → 새 레슨 순서가 곧 수업 순서다. 새 레슨의
  「강의 포인트」에 그 짝을 적는다.
- 대체가 아니라 *보강*이면(틀린 게 아니라 부족했던 것) `supersedes` 를 걸지 않고
  본문에서 상호 링크만 한다. 이 필드는 **선행 판단이 틀렸을 때만** 쓴다.

## 스킬

- `$lesson-log [주제]` — 최근 작업에서 레슨 추출·기록
- `$lesson-review [기간]` — 커밋/회의록 회고 스캔으로 누락 레슨 발굴 + INDEX/커리큘럼 맵 재생성
- `$socratic [대상]` — 기록한 레슨을 되먹이는 쪽. 답을 말하지 않고 질문만으로
  학습자가 스스로 도달하게 한다. 세션 중 막힌 지점이 곧 트리거 1·3 후보다
